# ReinforcementLearningFromScratch
Repository containing my work based on RLHF where I worked from scratch RLHF algorithms

## Content

Python scripts developed either on Kaggle notebooks or VSCode that implement common RLHF algorithms.

## Requirements 

* uv
* gymnasium
* numpy
* pytorch
